A program that writes the one line a gamer texts the boss to skip work during GTA 6 launch week: a burst boiler, a plumber ripping the floor up, and a morning stuck at home. At most 20 words, plain text, sent in a hurry.

## Run it

```sh
node main.ts
```

It writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
